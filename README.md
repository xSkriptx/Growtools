# Growtools - The Ultimate Growtopia Toolkit

A professional, high-performance web suite for Growtopia players. Built with React, TypeScript, and Tailwind CSS.

## 🚀 Live Demo
Check out the tools here: [https://xskriptx.github.io/Growtools/](https://xskriptx.github.io/Growtools/)

## 🛠️ Included Tools
- **DAT Decoder**: Analyze Growtopia binary data files.
- **Data Mining**: Real-time analysis of the latest game items.
- **Admin Checker**: Scan and analyze world lock permissions.
- **Growtopia News**: Live item leaks and official updates.
- **World Planner**: Design your worlds with an interactive grid.
- **Item Browser**: Search the complete database of 10,000+ items.
- **Level Calculator**: Plan your XP progression.
- **Server Monitor**: Track server uptime and player counts.

## 💻 Tech Stack
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Shadcn UI
- **Icons**: Lucide React
- **Visualization**: Recharts

## 📦 Local Setup

1. **Clone the repo:**
   ```bash
   git clone https://github.com/xSkriptx/Growtools.git
   cd Growtools
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
